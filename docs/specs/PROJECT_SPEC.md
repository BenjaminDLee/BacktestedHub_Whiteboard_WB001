# WB-001 Project Specification

## 1. Project Identity

Project: BacktestedHub_Whiteboard_WB001

Episode ID: WB-001

Working Title: Why Most People Lose Money in the Stock Market

Project Type: Financial educational whiteboard video

Target Channel: BacktestedHub

## 2. Primary Goal

Validate whether a locally produced whiteboard animation workflow can efficiently create original, educational financial videos suitable for YouTube.

## 3. Initial Success Criteria

The project is successful when:

1. The complete production pipeline can run from a topic/script to a playable MP4.
2. The workflow can run locally wherever practical.
3. The project environment is isolated from other projects.
4. The workflow is reproducible from the repository documentation.
5. Intermediate assets can be regenerated.
6. The final video has coherent narration, visuals, timing and audio.
7. The production process is documented well enough to repeat for WB-002 through WB-010.

## 4. Production Constraints

- Target hardware: RTX 5080 workstation
- Operating system: Windows
- Local-first architecture
- Free/open-source software preferred
- Cloud services may be used only when necessary
- No dependency should be installed into the global Python environment
- All project dependencies must be isolated

## 5. Content Direction

The video should explain a financial concept using:

- Original narration
- Original visual composition
- Whiteboard-style drawings
- Simple charts and diagrams
- Clear numerical examples
- Educational storytelling

## 6. Quality Priorities

Priority order:

1. Accuracy
2. Clarity
3. Narrative coherence
4. Audio quality
5. Visual readability
6. Rendering stability
7. Production speed
8. Visual polish

## 7. Automation Philosophy

Automate repetitive production tasks, but retain quality-control checkpoints.

The system must not blindly mass-produce interchangeable videos.

## 8. Current Phase

Phase 0 — Project initialization.

Next phase:

Environment setup and third-party dependency audit.
