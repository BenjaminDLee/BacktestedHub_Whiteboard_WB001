# BacktestedHub Whiteboard WB001

Whiteboard animation pilot project for the BacktestedHub financial content production system.

## Project

**Episode:** WB-001

**Working title:** Why Most People Lose Money in the Stock Market

## Objective

Build and validate a local-first, low-cost whiteboard video production pipeline for financial educational content.

The first milestone is not video quality. The first milestone is a reproducible production pipeline:

Topic -> Research -> Script -> Voice -> SRT -> Whiteboard Animation -> QA -> Final Video

## Principles

- Local-first
- Free/open-source software where practical
- Independent project environment
- Reproducible builds
- GitHub version control
- Human quality control before publishing
- Original educational content
- Avoid mass-produced repetitive content
